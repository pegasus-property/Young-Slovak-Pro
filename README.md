# Young Slovak PRO

A single-file clickable prototype of the Young Slovak PRO (YSP) website, styled after slovakpro.org.

- Open `index.html` in any browser. There is no backend; everything is sample data and nothing you type is saved or sent.
- Use the **View as** switch at the top to see the site as a Visitor, Member or Leader.
- Search the file for `TO CONFIRM` and `REPLACE with real photo from Drive` to find everything that still needs a real answer or a real photo.
